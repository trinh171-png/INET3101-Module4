# INET3101-Module4
Problem Statement

Improve the airline reservation system to save data after the program closes.

Describe the Solution

I used File I/O in C to save and load reservations using fwrite() and fread().

Pros and Cons

Pros:

Easy to use.

Saves data automatically.

Keeps reservations after restarting.

Cons:

Only supports 4 flights.

No graphical interface.
